# DNS: первый урок
> **Ссылка на сайт:** [Открыть DNS:как устроен интернет](https://chernichka03.github.io/dns-interactive-lesson/)
>
> 
Ты вводишь `google.com` в браузере, и появляется страница. Но как устройство узнаёт, к какому серверу подключиться? Этот сайт помогает разобраться в DNS: пройти путь от имени к адресу, прочитать ответ DNS и выбрать проверку, если сайт не открывается.

Здесь можно нажимать на карточки, переключать шаги схемы и пробовать разные ответы. Пояснения помогают понять свой выбор, а не просто запомнить правильную букву.

## Какие слова встретятся

| Слово | Что оно означает в этом уроке |
| --- | --- |
| Доменное имя | Удобное имя вроде `google.com`, которое мы вводим в браузере. |
| IP-адрес | Адрес, который устройство использует для подключения к нужному серверу. |
| DNS | Система доменных имён. Помогает получить данные по имени. Здесь мы ищем IP-адреса. |
| Резолвер | В нашей схеме это DNS-сервер, которому устройство задаёт вопрос. Он находит ответ и возвращает его устройству. |
| DNS-кеш | Сохранённые ответы, которые можно использовать повторно. Кеш бывает на устройстве и у резолвера. |
| Веб-сервер | Сервер, у которого браузер получает данные страницы: например, текст и картинки. |

## Как пройти сайт и какие задания есть

Сначала на главной странице предложи свою версию: компьютеру достаточно имени сайта или ему нужен адрес? Можно выбрать «пока не уверен». Это начало обсуждения.

Дальше идут шесть разделов:

| Раздел | Что делать | Что станет понятнее |
| --- | --- | --- |
| **01. Что такое DNS** | Посмотри пример с контактом «Аня». Открой «Подробнее» у четырёх карточек. | Чем имя отличается от адреса, что делает DNS-сервер и зачем нужен кеш. |
| **02. Путь от имени к адресу** | Нажимай «Следующий шаг». Можно вернуться назад, выбрать номер шага или начать схему заново. | Как запрос проходит от устройства к резолверу, как возвращается адрес и когда браузер обращается за страницей. |
| **03. Адрес найден. Что дальше?** | Ответь на один вопрос и прочитай пояснение. | Что именно мы получаем благодаря DNS. После правильного ответа появится «К практике». |
| **04. Прочитай ответ DNS** | Выбери пример, нажми «Выполнить», затем нажимай на строки результата. | Как читать ответ `nslookup` и отличать разные результаты проверки. |
| **05. Сайт не открывается** | Выбери первый шаг проверки. После правильного ответа появятся результат и второй вопрос. | Как проверять предположение о проблеме, а затем выбирать следующий шаг. |
| **06. Объясни своими словами** | Ответь на три вопроса. Если ошибся, прочитай подсказку и попробуй снова. | Умеешь ли ты объяснить основные идеи урока. |

В конце есть «Повторение», дополнительные карточки и короткий словарь. К ним удобно возвращаться, когда нужно уточнить термин.

### Как пользоваться окном nslookup

`nslookup` читается «эн-эс-лу́кап». Это команда, с помощью которой можно спросить DNS про имя.

1. В разделе «Прочитай ответ DNS» открой список «Выбери пример».
2. Начни с `google.com / пример ответа`.
3. Нажми «Выполнить».
4. Нажми на строку результата. Рядом появится объяснение именно этой строки.
5. После первого примера сравни два остальных результата.

| Пример | На что обратить внимание |
| --- | --- |
| `google.com / пример ответа` | Сверху указаны имя и адрес DNS-сервера, к которому обратились. Ниже строки `Name` находятся адреса Google. Это разные части ответа. |
| `missing.invalid / NXDOMAIN` | Сервер прислал ответ: запрошенного имени нет. Начни с проверки написания имени. |
| `example.com / тайм-аут` | Ответ вовремя не пришёл. По одному этому результату причину ещё нельзя определить. |

**В окне на сайте показаны заранее подготовленные ответы.** Они помогают разобраться в строках, но не проверяют соединение твоего компьютера. Настоящий запрос в Windows можно попробовать по инструкции в конце README.

### Что остаётся для самостоятельной работы

На занятии вместе с преподавателем разбираем схему, первый вопрос, пример с Google и итоговые вопросы. После первого примера `nslookup` для работы дома остаются:

1. Примеры `missing.invalid` и тайм-аут. Нажми на строку с результатом и объясни своими словами, чем «такого имени нет» отличается от «ответа не дождались».
2. Задание «Сайт не открывается». Пройди оба вопроса и объясни, зачем нужна каждая проверка.

Эту работу можно полностью выполнить на сайте. Настоящую команду в Windows выполняй дополнительно, если хочешь сравнить результат со своего компьютера.

## Нюансы, которые важно понять

- **Найти адрес и получить страницу - разные задачи.** DNS помогает с адресом. За содержимым страницы браузер обращается к веб-серверу.
- **Успешный ответ DNS ещё не означает, что сайт откроется.** Например, адрес известен, но сам веб-сервер может не отвечать.
- **NXDOMAIN и тайм-аут различаются.** В первом случае ответ получен, во втором мы не дождались ответа.
- **Non-authoritative answer - обычная ситуация.** Ответ пришёл от сервера, который не является авторитетным для запрошенной зоны. Сама надпись не означает ошибку или угрозу.
- **Кеш сохраняет ответ на время.** TTL показывает срок использования записи из кеша. В карточке 300 секунд - это пять минут. Истечение TTL само по себе не закрывает сайт.
- **У одного имени может быть несколько адресов.** Числа в примере не нужно учить наизусть. В настоящем запросе адреса и DNS-сервер могут отличаться.
- **Ошибаться в заданиях можно.** Выбранный ответ можно изменить. Кнопка «Разобрать задание заново» сбрасывает два вопроса в разделе про ошибку сайта.
- **Обновление страницы начинает работу заново.** Выборы хранятся в памяти открытой страницы. Кнопка «Повторить урок» также очищает ответы и окно практики, возвращает схему на первый шаг и закрывает карточки.

## Как устроен проект

Сайт сделан на HTML, CSS и JavaScript. Браузер загружает готовые файлы из папки и выполняет код JavaScript. Для локального запуска этой страницы отдельный веб-сервер и база данных не требуются.

В этом репозитории готовый сайт находится в корне: `index.html`, папки `css`, `js` и `assets` должны оставаться рядом с ним.

| Файл в репозитории | За что отвечает |
| --- | --- |
| `index.html` | Структура страницы: разделы, карточки, вопросы и кнопки. |
| `css/style.css` | Оформление: цвета, шрифты, расположение блоков, выделение ответов и адаптация к ширине экрана. |
| `js/lesson-data.js` | Данные урока: тексты шагов, примеры ответов DNS, пояснения и данные для проверки вариантов. |
| `js/script.js` | Поведение страницы: обработка нажатий, смена шагов, проверка ответов, показ пояснений и сброс. |
| `assets/favicon.svg` | Маленький значок сайта на вкладке браузера. |

SVG используется и для схемы внутри страницы. Это векторный рисунок: его линии и стрелки описаны кодом. При изменении размеров схемы JavaScript заново определяет края карточек и положение соединений.

### Что происходит после нажатия

**Шаги схемы.** Функция `showStep()` запоминает выбранный шаг, берёт его текст из данных урока, подсвечивает участников и нужную стрелку. Между браузером и резолвером видна одна связь: при запросе она направлена к резолверу, при возврате адреса - к браузеру. `networkRoutes()` рассчитывает линии, а `layoutNetworkDiagram()` размещает их с учётом размеров карточек.

**Ответ на вопрос.** Функция `answerQuestion()` находит выбранный вариант в данных урока. Затем выделяет ответ и показывает его пояснение. Она же сообщает другим частям страницы, что ответ изменился: например, после правильного ответа в разделе 03 появляется переход к практике.

**Задание про ошибку сайта.** Функция `updateCase()` проверяет, решён ли первый вопрос. Если да, показывает новый факт и второй вопрос. Итоговый вывод появляется после правильного ответа на оба вопроса. Если изменить первый ответ на неверный, второй этап снова скрывается и сбрасывается.

**Окно nslookup.** Функция `executeLookup()` берёт выбранный пример из `lesson-data.js` и создаёт строки результата. Каждая строка работает как кнопка. При нажатии `setLookupExplanation()` показывает её значение. Команда на компьютере при этом не запускается: весь разбор происходит в браузере.

**Карточки «Подробнее».** Здесь используются элементы HTML `<details>` и `<summary>`. Браузер сам открывает и закрывает их по нажатию. Отдельная программа для каждой карточки не нужна.

**Повторение.** Обработчик кнопки «Повторить урок» вызывает функции сброса, закрывает карточки и возвращает страницу к началу. Браузерная память с результатами очищается. Сохранения между открытиями страницы в этом проекте нет.

Если хочешь посмотреть код, открой файл через текстовый редактор, например Блокнот. В `script.js` можно найти названия этих функций поиском. Сначала попробуй сопоставить одну кнопку на сайте с той функцией, которая на неё реагирует.

## Как запустить сайт на своём компьютере

### На Windows

1. **Скачай ZIP целиком.** На странице репозитория нажми **Code**, затем **Download ZIP**.
2. **Распакуй архив.** Найди ZIP в папке «Загрузки», нажми на него правой кнопкой мыши и выбери **«Извлечь всё...»**. Выбери папку для проекта, например в «Документах», и нажми **«Извлечь»**.
3. **Открой распакованную папку.** Найди папку `dns-interactive-lesson` и открой файл `index.html` в её корне.
4. **Открой `index.html` двойным щелчком.** Он должен открыться в браузере. Если вместо сайта появился текстовый редактор, нажми на файл правой кнопкой мыши, выбери **«Открыть с помощью»** и укажи браузер, например Edge или Chrome.
5. **Проверь запуск.** Открой «Подробнее» у карточки, переключи шаг схемы, затем выбери пример `nslookup` и нажми «Выполнить». Если появляются тексты и пояснения, страница работает.

Готово: сайт запущен из папки на твоём компьютере. Для следующего запуска снова открой тот же `index.html`. Интернет нужен для скачивания архива, а после распаковки материалы и задания сайта работают без подключения.

**Переносить проект нужно целой папкой.** Сохраняй рядом с `index.html` папки `css`, `js` и `assets`. Если перенести только HTML-файл, страница потеряет оформление и интерактивные функции. Открывай файл из распакованной папки, а не из окна ZIP.

На macOS распакуй ZIP двойным щелчком, затем открой `index.html` или `dist/index.html`. На Linux извлеки ZIP средствами файлового менеджера и открой тот же файл в браузере.

### Если что-то не получилось

| Что ты видишь | Что проверить |
| --- | --- |
| Открылся текст с тегами `<html>` и `<body>` | Открой `index.html` через браузер с помощью «Открыть с помощью». |
| Страница есть, но выглядит как обычный текст без оформления | Проверь, что рядом с `index.html` есть `css/style.css`. Проще заново распаковать весь архив в новую папку. |
| Кнопки не реагируют | Проверь, что папка `js` распакована полностью и содержит оба файла. Попробуй открыть страницу в другом браузере. Для интерактивных заданий браузер должен разрешать JavaScript. |
| В окне nslookup ещё нет результата | Сначала выбери пример и нажми «Выполнить». Для пояснения нажми на строку появившегося ответа. |
| Не появился второй вопрос в задании про ошибку сайта | Он открывается после правильного ответа на первый вопрос. Прочитай пояснение и попробуй снова. |
| После закрытия или обновления страницы исчезли ответы | Это обычное поведение проекта. Результаты сохраняются только пока открыта текущая страница. |

### Дополнительно: настоящий запрос DNS в Windows

Эту часть можно попробовать после заданий на сайте. Здесь уже нужен доступ к интернету и DNS-серверу.

1. Нажми **Win + R**.
2. Введи `cmd` и нажми **Enter**. Откроется командная строка - окно, в котором можно вводить команды.
3. Введи команду:

   ```text
   nslookup google.com
   ```

4. Нажми **Enter** и дождись результата.
5. Если получен ответ с адресами, найди DNS-сервер в верхней части, а имя Google и его адреса - ниже. Сравни смысл строк с примером на сайте. Для выхода закрой окно.

Настоящий результат может отличаться от подготовленного примера. Если получен тайм-аут, это означает, что ответ вовремя не пришёл. Если пришёл ответ с адресами, поиск имени сработал; доступность самой страницы проверяется отдельно.

Официальные инструкции: [распаковка ZIP в Windows](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/zip-and-unzip-files), [скачивание проекта с GitHub](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives), [команда nslookup](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/nslookup).
